# 评估模块（eval/）

量化税务 Agent 表现，支撑"改好了还是改坏了"的迭代判断。这是让项目从"能跑"走向"可信"的关键一步。

## 目录结构

- `dataset.py` —— `EvalSample` 数据结构 + 内置 22 条税务问答评测集（覆盖 6 类意图 + 拒答场景）
- `metrics.py` —— 纯函数指标：意图准确率、关键词召回率、拒答正确率
- `run_eval.py` —— 命令行评测入口

## 怎么用

在项目根目录 `D:\code\tax_agent` 下执行：

```bash
# 1. 只测意图路由（纯本地，不需要 LLM 和向量库，秒级出结果）
python -m eval.run_eval --mode intent

# 2. 完整评测（需要 .env 里的 LLM + Qdrant 已配置，且知识库已灌入数据）
python -m eval.run_eval --mode all

# 3. 指定评测对象 / 导出 JSON
python -m eval.run_eval --agent knowledge_agent --mode answer --json report.json
```

## 三个指标的含义

| 指标 | 说明 | 理想值 |
|---|---|---|
| 意图路由准确率 | 路由到的意图 == 期望意图 的比例 | 越高越好 |
| 关键词召回率（宏） | 答案命中期望关键术语的平均比例 | 越高越好 |
| 拒答正确率 | 该拒答的拒答了、该回答的回答了 | 越高越好 |

## 设计说明

- **关键词只放稳定术语**（如"进项税""留抵""免征"），不放数字，避免 LLM 输出"8万"vs"80000"的格式差异造成误判。
- **拒答场景单独列**（`must_refuse=True`）：财税是高风险领域，Agent 在知识库无内容时"如实说不知道"比"编一个答案"更重要，所以把拒答正确率单列为指标。
- **意图评测离线可跑**：`HybridIntentRouter` 只依赖标准库，无需 LLM/向量库，方便你随时快速自测路由质量。
